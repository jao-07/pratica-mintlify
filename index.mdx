## Bem-vindo à Petstore API! 🐾

Esta documentação de exemplo foi gerada utilizando o **Mintlify** a partir de uma especificação OpenAPI 3.0. Aqui você encontrará tudo o que precisa para integrar e interagir com os serviços da nossa loja virtual.

Nossa API permite que você gerencie o catálogo de animais, controle o inventário da loja e administre os usuários do sistema de forma simples e rápida.

### Comece a explorar

Aproveite nossos endpoints interativos. Você pode visualizar os modelos de dados, verificar os parâmetros exigidos e testar requisições em tempo real diretamente do seu navegador.
